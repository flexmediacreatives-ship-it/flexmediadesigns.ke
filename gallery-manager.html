How do I get an access token?
  1. Sign in at github.com → click your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Give it a name (e.g. “Gallery Manager”) and choose an expiry date.
  3. Under Repository access choose Only select repositories and pick your website’s repository.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above. Keep it private — it works like a password for that one repository.

What do I do with the downloaded file?
  1. Unzip gallery-update.zip. Inside is a folder assets/images/gallery/ with your new images, and a file gallery.json.
  2. Copy them into your website project in the same places (replace the old gallery.json).
  3. Upload / deploy your project as usual.
